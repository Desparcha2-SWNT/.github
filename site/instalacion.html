Instalar la app en Android

La app se distribuye como APK firmado desde GitHub Releases. Escanea el código QR desde el celular o abre el enlace.

Pasos

  1. Escanea el código QR de esta página o abre la descarga de la app.
  2. Descarga el archivo .apk más reciente.
  3. Si Android lo pide, permite instalar desde esta fuente.
  4. Abre Festa e inicia sesión o regístrate.

Nota

El APK apunta al backend desplegado. Si el backend cambia de dirección, se publica un release nuevo con su QR. Esta página se actualizará con la versión vigente.

Pendiente: publicar un release nuevo con firma estable (los secretos de firma de festa-mobile aún no están creados).
