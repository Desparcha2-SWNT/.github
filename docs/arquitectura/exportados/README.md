# Diagramas exportados

Las imágenes se regeneran desde sus fuentes; no se editan a mano.

| Carpeta | Fuente | Cómo se regenera |
|---|---|---|
| 01-contexto, 02-contenedores, 03-componentes | `festa.dsl` (Structurizr) | Docker con `structurizr/structurizr local` y exportar la vista a PNG |
| 04-secuencias, 05-clases-y-bd, 06-despliegue, 07-casos-de-uso | Lucid (documento Festa) | Exportar la página a PNG |

Las clases y el modelo de datos de cada servicio están en la misma página de Lucid, por eso van juntos en 05-clases-y-bd.
